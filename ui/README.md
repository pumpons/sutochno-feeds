# Пульт фидов — деплой на Streamlit Cloud

Это веб-страница, через которую команда управляет сегментами и запускает пересборку фидов, не трогая код.

## Что нужно один раз

1. **Аккаунт на streamlit.io** — заходи через GitHub (тот же `pumpons`). На главной нажми `Deploy` → `From existing repo`.
2. **GitHub-токен** с правами `repo` и `workflow` (как при первой настройке). Сохрани его — пригодится для секретов пульта.
3. **Придумай пароль для команды** — это будет общий пароль для всех, кто заходит в пульт.

## Шаги деплоя

### 1. Опубликовать приложение

В streamlit.io → New app:
- **Repository:** `pumpons/sutochno-feeds`
- **Branch:** `main`
- **Main file path:** `ui/app.py`
- **App URL** (любое имя): например `pumpons-sutochno`

Нажми **Deploy**.

### 2. Добавить секреты

После деплоя зайди в `App settings` → `Secrets` и вставь туда (формат TOML):

```toml
app_password = "придумай-крепкий-пароль"
github_token = "ghp_..."
github_repo = "pumpons/sutochno-feeds"
github_branch = "main"
workflow_file = "daily.yml"
meta_base_url = "https://pumpons.github.io/sutochno-feeds/meta"
```

Сохрани — приложение само перезапустится.

### 3. Проверить

Открой `https://pumpons-sutochno.streamlit.app` (или какое имя выбрал).
Введи пароль из секретов → должен открыться список сегментов.

## Как пользоваться

- **Список сегментов** свёрнут по умолчанию — кликаешь на сегмент → видишь форму с фильтрами.
- **Изменил фильтры → Сохранить** = коммит в `config/segments.yaml`, но фид ещё не пересчитан.
- **Сохранить и запустить пересборку** = коммит + триггер GitHub Actions.
- **Запустить пересборку всех сегментов** (вверху) = триггер без изменений.
- **Статус последнего прогона** показан сверху: ⏳ идёт / ✅ успешно / ❌ ошибка.

## Поддержка списков городов и удобств

Выпадашки городов и удобств берутся из `output/meta/cities.json` и `output/meta/amenities.json`. Эти файлы создаёт пайплайн автоматически после каждой пересборки фидов — то есть актуальные списки появятся после первого прогона с обновлённым `ingest.py`.

Если выпадашки пустые — значит meta-файлы ещё не сгенерированы. Запусти любую пересборку, после неё списки наполнятся.
